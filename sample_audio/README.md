# Sample audio

`smoke_test_sample.wav` is a synthetic (sine-wave + harmonics + noise) clip
generated by `tests/conftest.py`'s approach - it's enough to exercise the
full pipeline (decode -> quality check -> inference -> response) but it is
**not real speech**, so treat its gender/age prediction as a plumbing check
only, not an accuracy check.

## Getting real speech samples

For a real accuracy smoke test, grab a handful of clips from Mozilla Common
Voice (CC0-licensed, includes self-reported age/gender metadata for a
subset of speakers):

1. Go to https://commonvoice.mozilla.org/en/datasets
2. Download any language's "Common Voice Corpus" (pick a small one, e.g.
   a recent delta release, to avoid the multi-GB full corpus)
3. Unzip; you'll get a `clips/` directory of `.mp3` files and a
   `validated.tsv` with `path`, `age`, `gender` columns
4. Smoke test one clip directly against a running server:

   ```bash
   curl -X POST http://localhost:8000/analyze \
     -F "file=@/path/to/cv-corpus/en/clips/common_voice_en_12345.mp3"
   ```

5. Or run the full eval harness against many labeled clips:

   ```bash
   python eval/eval_common_voice.py \
     --tsv /path/to/cv-corpus/en/validated.tsv \
     --clips-dir /path/to/cv-corpus/en/clips \
     --limit 300
   ```

No Common Voice audio is included in this repo to keep it small and to
avoid redistributing third-party recordings.
